Первый запрос

Получим сводку за 5 февраля 2024 года. По умолчанию границы дня считаются в UTC.

cURL
curl --get 'https://gram.rin.ms/v1/ton/price' \
  --data-urlencode 'at=2024-02-05'

В data.segments придут первая, последняя, минимальная и максимальная цены. Для цены на точный момент передайте at=2024-02-05T12:00:00+03:00.

Проверить на главной

Справочник методов

Все методы используют GET. Параметры передаются в строке запроса.

Схема OpenAPI

Курс на дату

Проверить запрос
GET/v1/ton/price

Принимает два формата. at=2024-02-05 возвращает сводку за день: первая, последняя, минимальная и максимальная цены. at=2024-02-05T09:00:00Z возвращает одну цену не позднее указанного момента.

Параметры запроса курса на дату
ПараметрЗначениеОписание
atобязательныйДата и времяYYYY-MM-DD для сводки или RFC 3339 с секундами и часовым поясом для одной цены.
timezoneUTC по умолчаниюЧасовой пояс для простой даты, например Europe/Moscow. Точная дата со временем использует собственное смещение.
max_age_seconds0–86400 · по умолчанию 900Допустимый возраст записи для запроса с точным временем. Для дневной сводки не применяется.
seriesreferenceВыбор источника. Доступные серии

Для точного времени: 404 DATA_GAP при слишком старой записи и 404 PRICE_NOT_FOUND при отсутствии записи. Для простой даты без данных: 200, пустой segments и предупреждение NO_DATA. Сегодняшняя сводка помечена is_day_complete: false; будущая дата возвращает 422.

Текущий курс

Проверить запрос
GET/v1/ton/price/latest

Последняя доступная цена относительно текущего времени. Новые наблюдения TON/USD поступают из Calcmula каждые пять минут.

Принимает series и max_age_seconds с теми же значениями, что и запрос на дату. Ответ содержит age_seconds — возраст записи в секундах.

Если запись старше допустимого значения, API вернёт 503 PRICE_STALE. Старая цена не выдаётся за свежую.

История за период

Проверить запрос
GET/v1/ton/history

Записи в порядке времени за диапазон [from, to): начало включено, конец исключён. Максимальный диапазон — 366 дней.

Параметры запроса истории
ПараметрЗначениеОписание
from, toобязательныеRFC 3339Границы периода с часовым поясом. Конец не позже текущего момента.
limit1–1000 · по умолчанию 500Количество записей на странице.
cursorСтрока · необязательныйЗначение meta.next_cursor из предыдущего ответа.
seriesreferenceСерия цен.

Для следующей страницы передайте cursor, сохранив прежние from, to, series и limit. Когда next_cursor: null, данные закончились.

Сводка за день

Проверить запрос
GET/v1/ton/daily

Первая, последняя, минимальная и максимальная сохранённые цены за календарный день. Границы дня определяются выбранным часовым поясом. Это та же сводка, что у /v1/ton/price?at=2024-02-05; здесь дата передаётся в параметре date.

Параметры суточной сводки
ПараметрЗначениеОписание
dateобязательныйYYYY-MM-DDНапример, 2024-02-05.
timezoneUTC по умолчаниюЗона IANA, например Europe/Moscow. Переходы на летнее время учитываются.
seriesreferenceСерия цен.

Это статистика сохранённых наблюдений, а не биржевая свеча. Если в один день встречаются USD и USDT, они возвращаются отдельными элементами data.segments.

Покрытие и состояние

Проверить запрос
GET/v1/ton/coverage

Границы истории, количество записей по источникам, момент перехода на Calcmula и состояние сборщика. Принимает необязательный series.

collector.last_success_at — время последней успешной записи в Unix seconds; consecutive_failures — число ошибок подряд. known_gap_count: null означает, что число пропусков для серии не подсчитано.

/health/liveПроцесс API отвечает
/health/readyБаза доступна для чтения

Успешный health-запрос не гарантирует свежий курс. Для этого проверяйте /price/latest или время последней записи.

Скачать всю базу

GET/v1/ton/export

Полный снимок SQLite, сжатый gzip: все серии цен, исходные сообщения публичного канала и метаданные. Отдельный процесс готовит файл каждые 5 минут через SQLite backup API, включая зафиксированные записи WAL. Скачивание получает готовый снимок.

Скачать базу .sqlite3.gz

cURL
curl --fail --location --output gram-prices.sqlite3.gz \
  'https://gram.rin.ms/v1/ton/export'
gzip --decompress gram-prices.sqlite3.gz

Успех — бинарный application/gzip, без оболочки data/meta. Параметров нет: выгружаются все серии и даты. Таблицы: prices, live_prices, raw_messages, metadata, collector_state. Общее представление цен — price_observations.

Заголовки полной выгрузки
ЗаголовокСодержание
Content-LengthРазмер сжатого файла в байтах.
X-Snapshot-Created-AtВремя создания согласованной копии, UTC.
X-Snapshot-Age-SecondsВозраст копии на момент ответа.
X-Checksum-SHA256SHA-256 сжатого файла.
ETagПередайте его в If-None-Match; неизменившийся файл вернёт 304.

HEAD /v1/ton/export возвращает эти заголовки без скачивания. Файл кэшируется на 60 секунд. Range не поддерживается. Если снимок ещё не готов — 503 EXPORT_UNAVAILABLE; старше 15 минут — 503 EXPORT_STALE. Повторите через время из Retry-After. Ошибки возвращаются в стандартном application/problem+json.

Время и пропуски

Простая дата 2024-02-05 означает календарный день в указанном timezone, по умолчанию UTC. Ответ — сводка по сохранённым наблюдениям, с разделением валют. Если нужна одна цена, передайте дату со временем, секундами и часовым поясом. Два запроса ниже означают один момент:

2024-02-05T09:00:00Zэто2024-02-05T12:00:00+03:00

В URL знак + нужно кодировать как %2B. Используйте URLSearchParams, urlencode или curl --data-urlencode, как в примерах на главной.

Запись до запроса, а не после

Для запроса на 12:00 запись на 11:58 подходит, а запись на 12:03 — нет. Интерполяции между ценами нет. По умолчанию подходит запись не старше 15 минут; это ограничение задаёт max_age_seconds.

В архиве есть пропуски: пятиминутный интервал — частота сбора, а не обещание наличия каждой точки. При остановке источника пропущенные цены не восстанавливаются автоматически.

Источники и валюты

У каждой записи есть собственная валюта и источник. Исторический знак $ сохранён как USD; новые котировки Calcmula выражены в USD. Ранее собранный участок USDT сохранён с исходной валютой.

referenceПо умолчанию

Telegram до первой записи Calcmula, затем Calcmula. Переход к Calcmula отмечен в data.cutover_at, переход с USDT на USD — в data.usd_cutover_at ответа /coverage.

telegram-usdАрхив · USD

451 000 цен из канала @tonprices, начиная с 15 декабря 2021 года. Источник первоначальной котировки канала неизвестен.

calcmula-usdНовые записи · USD

Результат конвертации 1 ton in usd через Calcmula. Один снимок цены за пятиминутный интервал.

calcmula-usdtПрежние записи · USDT

Сохранённые наблюдения до перехода на USD. Сбор этой серии прекращён; значения не пересчитаны и не переименованы.

Время получения — не время биржевой сделки. Calcmula не сообщает время обновления исходного курса. Поэтому для новых записей timestamp_basis равен retrieval_time, а provider_updated_at — null.

USD и USDT не пересчитываются друг в друга. В reference проверяйте quote_currency каждой записи. market-usdt зарезервирован, но пока не содержит данных.

Формат ответа

Успешный JSON-ответ содержит data и meta. В зависимости от метода data — одна цена, список записей или сводка. У /price форма зависит от at: точное время возвращает цену, простая дата — data.kind: "daily_summary" с массивом segments. В каждом сегменте есть first, last, min, max, валюта и число записей.

Основные поля ответа с ценой
ПолеЧто означает
data.priceЦена строкой. Для расчётов используйте Decimal или библиотеку точной десятичной арифметики.
data.quote_currencyUSD или USDT.
data.observed_atВремя наблюдения в UTC: публикация сообщения или получение ответа провайдера.
data.requested_atЗапрошенный момент. Поле методов price и latest.
data.age_secondsРазница между запрошенным временем и временем наблюдения.
data.source.providertelegram или calcmula.
meta.request_idИдентификатор запроса. Также передаётся в заголовке X-Request-ID.
meta.warningsПояснения об источнике, валюте и ограничениях времени. Предупреждение не делает ответ ошибкой.

Полная схема всех полей доступна в OpenAPI. Для просмотра моделей и ручных запросов есть Swagger UI.

Ошибки

Проверяйте HTTP-статус перед чтением data. Ошибки возвращаются в формате application/problem+json по RFC 9457, без оболочки data/meta.

Для Python-клиента задайте User-Agent: GramPricesClient/1.0, как в примере на главной. Cloudflare может отклонить стандартный User-Agent urllib с ответом 403 / 1010 до обращения к API; такой ответ не имеет формата data/meta или problem+json.
